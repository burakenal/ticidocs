# Ticidocs

Ticidocs; API, SDK ve ürün dokümantasyonu için açık kaynaklı, kendi sunucunuzda çalışan bir platformdur. Mintlify benzeri modern bir deneyim sunar; ancak mimari, UI ve kod tabanı bağımsızdır.

Git’te tutulan MDX içerik ile locale-first routing, yerleşik SEO ve OpenAPI referansını tek bir Next.js sitesinde birleştirir. Zorunlu SaaS, bulut veritabanı veya harici kimlik doğrulama servisi yoktur.

<Callout type="info">
Bu site, monorepo içindeki `@ticidocs/docs` dogfood uygulamasıdır. Aynı içerik modeli `examples/full` ve `create-ticidocs` şablonlarında da kullanılır.
</Callout>

### Özellik özeti

| Alan | Ne yapar |
| --- | --- |
| **İçerik** | Git tabanlı MDX; frontmatter ile başlık, sıra, SEO alanları |
| **Diller** | `locales` / `defaultLocale`; eksik çeviride fallback + banner |
| **Navigasyon** | Gruplar, sayfa listesi ve `openapi` grupları |
| **Arama** | Yerel indeks; `Ctrl` / `Cmd` + `K` |
| **API** | OpenAPI 3.0/3.1 → method badge, şema, auth, Try It |
| **Dağıtım** | Docker, VPS, Kubernetes veya herhangi bir Node host |

## Kimler için?

- REST API ve OpenAPI dokümantasyonu yazan ekipler
- SDK / geliştirici portalı yayınlayan ürünler
- İç teknik dokümantasyonunu self-hosted tutmak isteyen organizasyonlar
- Angular, React veya .NET ürünlerini docs sitesine link / iframe / reverse proxy ile bağlayan ekipler

Ticidocs bir **dokümantasyon sitesi motorudur**; ürününüze gömülü bir CMS değildir.

## Mimariye kısa bakış

```text
content/{locale}/*.mdx  →  @ticidocs/mdx
docs.config.ts          →  @ticidocs/config + @ticidocs/core
openapi/*.yaml          →  @ticidocs/openapi
                        ↓
              apps/docs (Next.js App Router)
                        ↓
         /{locale}/...  +  /sitemap.xml  +  /robots.txt
```

- **URL:** `/{locale}/...` — örnek: `/tr/getting-started`, `/en/authentication`
- **Aynı göreli path:** `getting-started.mdx` hem `en` hem `tr` altında; dil değişince slug korunur
- **Fallback:** Bir locale’de dosya yoksa `defaultLocale` içeriği gösterilir (ör. `/tr/advanced`)
