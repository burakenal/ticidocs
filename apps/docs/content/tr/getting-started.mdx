# Başlangıç

Bu sayfada monorepo’yu yerelde çalıştırma, `docs.config.ts` ayarları ve MDX içerik ekleme adımları yer alır.

<Callout type="tip">
Monorepo için **pnpm** kullanın. npm ve yarn çalışabilir; desteklenen paket yöneticisi pnpm’dir. Node.js **20+** gerekir.
</Callout>

## Hızlı başlangıç

```bash
pnpm install
pnpm dev
```

Tarayıcıda [http://localhost:3000](http://localhost:3000) açın — `/` varsayılan locale’e (`en`) yönlendirilir. Türkçe için `/tr` veya `/tr/getting-started` kullanın.

Yeni bir site iskelelemek için:

```bash
pnpm --filter create-ticidocs build
pnpm --filter create-ticidocs start my-docs --template=full --link --yes
```

Şablonlar: `basic` (yalnız MDX), `api` (OpenAPI odaklı), `full` (MDX + OpenAPI + Try It).

## Kurulum adımları

<Steps>
  <Step title="Bağımlılıkları kur">
    Repo kökünde `pnpm install` çalıştırın. Turborepo workspace paketlerini bağlar.
  </Step>
  <Step title="Docs uygulamasını başlat">
    `pnpm dev` çalıştırıp `http://localhost:3000` adresini açın. Geliştirme sunucusu `@ticidocs/docs` filtresiyle ayağa kalkar.
  </Step>
  <Step title="İçeriği düzenle">
    `apps/docs/content/en` ve `content/tr` altına MDX ekleyin veya mevcut dosyaları güncelleyin. Aynı göreli path’i her iki dilde tutun.
  </Step>
  <Step title="Navigasyonu güncelle">
    Yeni sayfayı `docs.config.ts` içindeki `navigation` gruplarına ekleyin; aksi halde sidebar’da görünmez.
  </Step>
</Steps>

## docs.config.ts

Minimum geçerli yapılandırma:

```ts
import { defineConfig } from "@ticidocs/config";

export default defineConfig({
  name: "Ticidocs",
  description: "Open-source documentation platform",
  siteUrl: "https://docs.ticidocs.dev",
  locales: ["en", "tr"],
  defaultLocale: "en",
  navigation: [
    {
      group: "Getting Started",
      pages: ["index", "getting-started", "authentication", "advanced"],
    },
    {
      group: "API Reference",
      openapi: "./openapi/openapi.yaml",
      basePath: "api",
    },
  ],
  theme: {
    primaryColor: "#0055FF",
  },
  api: {
    // Try It yalnızca bu origin’lere istek atabilir
    allowedOrigins: ["https://api.example.com"],
  },
});
```

| Alan | Açıklama |
| --- | --- |
| `siteUrl` | Canonical, hreflang ve sitemap için zorunlu |
| `locales` / `defaultLocale` | Dil listesi ve `/` yönlendirme hedefi |
| `navigation` | Sidebar grupları; `pages` veya `openapi` |
| `api.allowedOrigins` | Try It SSRF koruması; listedeki host’lar dışında istek yok |
| `github.url` | Navbar’da repo bağlantısı (opsiyonel) |

## MDX ve frontmatter

Her sayfa YAML frontmatter ile başlar:

```mdx
---
title: Başlangıç
description: Ticidocs'u yerelde kurun
sidebarTitle: Başlangıç
order: 2
---

# Başlangıç

İçerik buraya...
```

Desteklenen alanlar: `title`, `description`, `sidebarTitle`, `slug`, `draft`, `order`, `icon`, `noindex`.

MDX içinde kullanabileceğiniz bileşenler:

| Komut | Ne yapar |

## Doğrulama

Kurulumdan sonra şunları kontrol edin:

- `/en/getting-started` ve `/tr/getting-started` açılıyor
- Dil seçici aynı slug’da kalıyor
- `/tr/advanced` İngilizce fallback + çeviri banner’ı gösteriyor
- `/sitemap.xml` ve `/robots.txt` üretiliyor
- `Ctrl` / `Cmd` + `K` ile arama açılıyor
