Ticidocs combines Git-backed MDX content, locale-first routing, built-in SEO, and OpenAPI reference pages in a single Next.js site. There is no mandatory SaaS, cloud database, or external auth service.

<Callout type="info">
This site is the `@ticidocs/docs` dogfood app inside the monorepo. The same content model is used by `examples/full` and the `create-ticidocs` templates.
</Callout>

### Feature summary

| Area | What it does |
| --- | --- |
| **Content** | Git-based MDX; frontmatter for title, order, and SEO fields |
| **Locales** | `locales` / `defaultLocale`; missing translation → fallback + banner |
| **Navigation** | Groups, page lists, and `openapi` groups |
| **Search** | Local index; `Ctrl` / `Cmd` + `K` |
| **API** | OpenAPI 3.0/3.1 → method badge, schemas, auth, Try It |
| **Deploy** | Docker, VPS, Kubernetes, or any Node host |

## Who is it for?

- Teams publishing REST / OpenAPI documentation
- Products shipping SDK or developer portals
- Organizations that want self-hosted internal technical docs
- Teams linking Angular, React, or .NET products via link / iframe / reverse proxy

Ticidocs is a **documentation site engine**, not an embedded CMS for your product.

## Architecture at a glance

```text
content/{locale}/*.mdx  →  @ticidocs/mdx
docs.config.ts          →  @ticidocs/config + @ticidocs/core
openapi/*.yaml          →  @ticidocs/openapi
                        ↓
              apps/docs (Next.js App Router)
                        ↓
         /{locale}/...  +  /sitemap.xml  +  /robots.txt
```

- **URL:** `/{locale}/...` — e.g. `/en/getting-started`, `/tr/authentication`
- **Same relative path:** `getting-started.mdx` under both `en` and `tr`; the slug is preserved when switching language
- **Fallback:** If a locale file is missing, `defaultLocale` content is shown (e.g. `/tr/advanced`)
